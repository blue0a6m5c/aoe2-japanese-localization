## 起動・読込・退行

- [ ] メインメニュー、設定、スカーミッシュ設定が正常な日本語で表示される。
- [ ] ローカルMod一覧にPhase 1F Testが現れ、有効化できる。
- [ ] 「射手育成所」「包囲攻撃訓練所」で日本語overrideの読込を確認する。
- [ ] Mod無効化→再起動で元のDE表記へ戻ることを確認する。
- [ ] 通常ユニット名、上位/精鋭ユニット名、建物名、テクノロジー名を確認する。
- [ ] 作成・研究・アップグレードボタンと選択中ユニットの表示を確認する。
- [ ] Help見出しが採用訳と一致する。
- [ ] Help本文が欠落せず、価格・効果・説明が正常に表示される。
- [ ] 今回未変更のHelp本文の旧表記を見つけた場合は別途記録する（自動修正しない）。
- [ ] 太字/斜体等のmarkupが崩れず、`<b>`、`<i>`、`<cost>`、`%s`等が不自然に露出しない。
- [ ] `\n`が文字として露出せず、意図した改行として表示される。
- [ ] 標準UIスケールと普段のUIスケールで、文字切れ・重なり・枠外へのはみ出しがない。
- [ ] コストやHelpの可変値に欠落・文字化け・placeholderの残留がない。
- [ ] 未変更の画面やシナリオの名称が想定外に変わっていない。
- [ ] 今回の差分パッケージだけを使用し、旧全文方式のModを同時に有効化していない。

## 人間が改行を指定した13位置

**技術ツリーの小さな名称欄を第一候補**とするのは表示形態からの推定。
現在の資料にはUIレイアウト/datの参照先がないため、これらのIDが使われる画面を断定しない。

## 問題を発見した場合

画面・build・解像度・有効Mod・ID候補・期待値・実値・画像名を記録する。
ゲーム本体やsourceを直接修正しない。裁定変更が必要なら、新しい人間レビューとして提案する。
起動やメニューに問題があればModを無効化して再起動し、無効時にも再現するか分けて記録する。
